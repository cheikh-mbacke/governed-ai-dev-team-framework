# Example: Project A

This example shows the **shape** of an initialized project after the human material has been registered and the Project Compiler has produced an execution model.

It is not copied by the installer. Read-only reference — optional, not a prerequisite to using the framework.

- `source-registry.yaml` — one registered product source.
- `product/requirements.md` — the human material that source points to.
- `WU-001.yaml` — a compiled Work Unit, including risk class and required verification.
- `CTX-WU-001.yaml` — the Context Package built for that Work Unit.
