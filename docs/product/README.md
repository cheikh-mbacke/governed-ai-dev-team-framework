# Human product material

In an installed project, put authoritative product artifacts here or register authoritative files from their actual repository locations in `.ai-team/sources/source-registry.yaml`.

Typical material:
- vision and measurable objectives;
- scope / out-of-scope;
- actors and user journeys;
- business rules and invariants;
- functional and non-functional requirements;
- acceptance criteria;
- architecture and interface contracts;
- technical, operational, security and compliance constraints;
- reference data, examples or required proof artifacts.
