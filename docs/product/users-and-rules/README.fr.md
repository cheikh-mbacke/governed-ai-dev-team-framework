# Utilisateurs et règles

- Acteurs, utilisateurs, cas d'usage ou parcours attendus — qui utilise le système, et comment ?
- Règles métier, invariants et décisions fonctionnelles — quelles règles, invariants, décisions et exceptions gouvernent le comportement ?

Si ce produit a une interface utilisateur, précisez aussi les appareils
ciblés (mobile, desktop, tablette, ou explicitement tous) et l'objectif/
contexte d'usage principal pour chaque acteur. Un agent Frontend Developer
doit poser une question plutôt qu'inventer cette information — voir
`.ai-team/constitution/35-ui-ux-strategy.yaml`.
