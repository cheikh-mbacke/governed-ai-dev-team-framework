# Users and rules

- Actors, users, expected use cases or journeys — who uses the system, and how?
- Business rules, invariants and functional decisions — what rules, invariants, decisions and exceptions govern behavior?

If this product has a user interface, also say what devices it targets
(mobile, desktop, tablet, or explicitly all) and the primary goal/context
of use for each actor. A Frontend Developer agent is required to raise a
question rather than invent this — see
`.ai-team/constitution/35-ui-ux-strategy.yaml`.
